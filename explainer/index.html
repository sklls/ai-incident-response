How it is built

One commander. Four tiers. No improvising.

The commander never guesses the order of work. It opens a case, runs the six phases top to bottom, and pulls in a specialist when the failure calls for one.

Underneath sit the shared parts every step leans on: a way to score how bad it is, the gate that waits for a person, the record that cannot be quietly edited, and a map of which laws apply. Build them once, use them everywhere.

And each skill carries the rule it enforces on its sleeve — EY's agent guardrails, the four-fifths rule, India's DPDP Act and IT Act, ISO 42001. The library is the governance framework, written so it actually runs.

The rule that matters

The agent proposes. A person approves.

A click in a browser cannot nudge the agent forward on its own. So the agent writes down what it wants to do, stops its turn, and sits still.

It starts again only when it reads an approved record in the database. A spoken "go ahead" does nothing. The agent believes the file, not the room.

record says pending  →  it waits
record says rejected  →  it holds, and offers another way
no record  →  no action

Approve, reject, or still waiting — and the name of whoever decided — all of it lands in the record. That is the difference between oversight you can prove and oversight you merely remember.

How each skill works

Read something. Do one job. Write it back.

Every skill has the same shape: it takes a few things in, runs a short routine, and leaves a record behind. The flow under each one shows exactly what goes in, what it does, and what it writes. They run as you reach them.

In the field

One line of work. Three ways to stop the harm.

The steps hold steady. What changes is the specialist, the shape of "stop it", and the law with its hand up. A leak gets shut down. An unfair model gets a human in the loop. A runaway agent loses its keys.

S1 · privacy

A chatbot shows one customer another's data

stop it by: shutting it down
  • first question: one chat, or many?
  • cause: a cache served across sessions
  • clocks: CERT-In 6h, then DPDP 72h
S2 · fairness

A hiring model turns one group away more often

stop it by: routing to human review
  • test: four-fifths, and a significance check
  • cause: a stand-in for a protected trait
  • law: Articles 14/15, NITI, EEOC
S1 · autonomy

A finance agent pays past its limit

stop it by: taking its keys
  • cause: an instruction hidden in an invoice
  • fix: a hard limit outside the model
  • law: IT Act §11, RBI FREE-AI
